Verified rule for how code reaches Studio.

## Verified facts

- `HabulanRush.rbxlx` is generated by the Rojo build. Never hand-edit it (AGENTS.md:58).
- Never edit scripts inside Studio. Edit `src/`, rebuild, or the change is lost (AGENTS.md:59).
- Reopen the place on the fresh build before testing, so Studio never runs stale scripts.
- Build command from the repo root: `rojo build default.project.json -o HabulanRush.rbxlx`, using `%LOCALAPPDATA%\rojo-bin\rojo.exe` when rojo is not on PATH.
